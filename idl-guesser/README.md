# IDL Guesser

**Forked from [SEC3's IDL Guesser](https://github.com/sec3-service/IDLGuesser)**

IDL Guesser is an open-source tool that automatically recovers the IDL information from closed-source Anchor-based Solana programs. This version is maintained as part of the Solana Transaction Monitor Tool to ensure availability and long-term support.

Check out [SEC3's blog post](https://www.sec3.dev/blog/idl-guesser-recovering-instruction-layouts-from-closed-source-solana-programs) for an in-depth discussion of how the tool works and the ideas behind it.

## Why Forked?

This is a fork of SEC3's IDL Guesser integrated into our repository to:
- Ensure long-term availability (no dependency on external repos)
- Maintain compatibility with our transaction monitoring tool
- Allow custom modifications if needed
- Provide a stable, tested version

**Original Repository**: https://github.com/sec3-service/IDLGuesser  
**Credits**: All credit for the IDL Guesser goes to the SEC3 team

## Installation

This tool is built automatically when you build the main Solana Transaction Monitor Tool:

```bash
# From the repository root
make setup
```

Or build manually:

```bash
cd idl-guesser
cargo build --release
```

## Usage

Run the tool from the command line:

```bash
Usage: idl-guesser [OPTIONS] <PROGRAM_ID>

Arguments:
  <PROGRAM_ID>  The program ID to analyze

Options:
  -u, --url <URL>    Solana JSON RPC endpoint [default: https://api.mainnet-beta.solana.com]
  -v, --verbose      Verbose logging
  -f, --force-guess  Force guess the IDL even if a public IDL exists
      --export-asm   Export the disassembled assembly code to asm.txt
  -h, --help         Print help
```
